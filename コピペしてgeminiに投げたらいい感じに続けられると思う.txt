## 🛠️ Partner's Assignment: Category CRUD

Implement a full Category management feature (Create, Read, Update, Delete).
No image uploads or complex relationships required. Treat it like a standard "Todo list" app where tasks are swapped with "Category names".

### Pre-defined Routing (Do NOT edit `routes/web.php`)

All routes are already registered under the `auth` middleware group:

* `GET: /categories` -> `CategoryController@index` (Name: `categories.index`)
* `POST: /categories/create` -> `CategoryController@store` (Name: `categories.store`)
* `GET: /categories/{id}/edit` -> `CategoryController@edit` (Name: `categories.edit`)
* `POST: /categories/{id}/update` -> `CategoryController@update` (Name: `categories.update`)
* `DELETE: /categories/{id}` -> `CategoryController@destroy` (Name: `categories.destroy`)

### Absolute Target Files (Only modify these files)

* **Controller:** `app/Http/Controllers/CategoryController.php` (Create if missing)
* **Model:** `app/Models/Category.php`
* **Migration:** Create standard `categories` table (fields: `id`, `name`, `timestamps`)
* **View:** `resources/views/categories/index.blade.php` (Blade + Tailwind CSS)
